# 🍔 Swiggy Clone - React Application

A front-end Swiggy clone built using **React** as part of a learning project. This application focuses on replicating the user interface and primary interactions of the popular food delivery platform while utilizing modern React concepts to build dynamic, scalable, and efficient components.

---

## 🚀 Features

- **React Concepts**: Demonstrates in-depth knowledge of React fundamentals, including components, props, state, and lifecycle methods.
- **React Router DOM**: Implements navigation and routing between multiple pages, such as the homepage, restaurant listings, and order details.
- **Redux Integration**: Manages application state efficiently using Redux, providing a robust architecture for handling data flow.
- **Dynamic Rendering**: Showcases dynamic rendering of restaurant menus, food items, and user interactions.
- **Responsive Design**: Optimized for various devices, ensuring a seamless experience on desktops, tablets, and smartphones.

---

## 🌐 Technologies Used

- **React**: For building UI components and managing the application’s frontend logic.
- **React Router DOM**: For handling client-side routing.
- **Redux**: For state management across the application.
- **Tailwind CSS**: For utility-first styling and rapid UI development.

---

## 📖 Learning Outcomes

This project was undertaken to explore and deepen understanding of React and its ecosystem. Key takeaways include:

- Building reusable and modular components.
- Understanding and implementing Redux for state management.
- Mastering React Router DOM for navigation and routing.
- Debugging and optimizing React applications.
- Creating responsive designs with React.
